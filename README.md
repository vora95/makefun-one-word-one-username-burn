# One Word, One Username, One Reward — gentle-lynx-64

Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/competitions/u-rusdyxbt-one-word-one-username-one-reward-1a191fae): the program writes one text to `/output/entry.txt` — the entrant's own make.fun username, one word.

The username is **gentle-lynx-64** — the entrant's own handle, exactly as it is. No explanation, no link, no pitch: the handle itself is the entry.

`main.py` writes the single username to `/output/entry.txt` and verifies it by reading it back byte-for-byte.
